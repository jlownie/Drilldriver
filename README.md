# Drilldriver
Software for practicing drills of various kinds.

Drilldriver takes the specification of a training/practice activity (eg, a description of the information that will be presented to the user) and programatically generates a CSV file that is then imported into Anki.  Anki then presents a series of prompts to the user.

The specification is in the form of a set of variables and their possible values.  This makes it possible to quickly generate a large set of prompts from a small amount of input data.
